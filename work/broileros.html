PRODUCT SCREENSHOT — DASHBOARD
01PROBLEM

Running a broiler operation without proper software means tracking everything in a notebook — batch start dates, bird counts, daily mortality, feed consumption, medication records, and cost summaries across a cycle that runs 6-8 weeks. When multiple batches overlap, the mental overhead compounds fast.

Off-the-shelf farm management platforms are expensive, built for different markets, and carry features nobody in a small operation needs.

02PROCESS

The data model came first: batches as the primary entity, daily records hanging off each batch, and a cost layer tracking inputs — chicks, feed, medication, utilities — against projected and actual output. This mirrors how broiler farming actually works; the batch is the unit of measurement for everything.

UI design was driven by the use case: a phone screen inside a chicken house. Large tap targets. Minimal navigation depth. Fast data entry for the daily log. The dashboard surfaces the numbers that matter at the start of the day — active batches, current mortality rate, feed conversion ratio trend, cost-per-bird running total — without requiring any navigation to find them.

Built solo from schema to deploy. Auth handled by Supabase with row-level security so farm data stays private.

03SOLUTION

A full-stack web app that replaces the notebook. Batch creation, flock health tracking, mortality logging, feed management, and cost monitoring. Everything is per-batch — no aggregate confusion when cycles overlap. Mobile-first, fast to load, no subscription.

The hardest call was deciding what not to build. A poultry management system can grow into veterinary records, supplier management, payroll, market price tracking. BroilerOS does the daily log, the batch summary, and the cost sheet. That's what was actually needed. Everything else waits until it earns its place.

04RESULT

Replaced manual tracking for an active broiler operation. Live and in daily use, with the client relying on it through full production cycles. Designed, built, and deployed end to end.
